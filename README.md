One original dad joke, one line, 64 characters, for make.fun's "The One-Liner Groan-Off" bounty ($2, top 10). A judge model reads the jokes two at a time and weighs how well each lands as a dad joke, how fast the punchline arrives, how fresh it is, how tight the wording is, and how good the groan is.

The program writes the joke to `/output/entry.txt` (gate: 1–140 characters).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
